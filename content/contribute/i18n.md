## Translations & Localization (i18n)

Daemontalk officially supports 2 languages: **English (`en`)** and **Indonesian (`id`)**. You can help localize dispatches or UI strings.

---

## 1. Localizing Technical Dispatches

Dispatches are stored with standard language-code suffixes:

| Language | File Location | Example |
| :--- | :--- | :--- |
| **English (Default)** | `content/posts/[slug].md` | `os-oom-killer.md` |
| **Indonesian** | `content/posts/[slug].id.md` | `os-oom-killer.id.md` |

Ensure the `slug` and `date` in the frontmatter match across languages so the router links translations seamlessly.

---

## 2. Localizing UI Strings

Platform dictionaries are stored under `internal/i18n/`:
- `en.go`: English dictionary
- `id.go`: Indonesian dictionary

Open a Pull Request to refine or expand dictionary terms.
