## Article Corrections & Code Snippet Fixes

All technical dispatches on Daemontalk are open-source Markdown documents stored under `content/posts/`. We welcome fixes for typos, code bugs, and broken references.

---

## 2 Ways to Submit Corrections

### Method 1: 1-Click Edit via GitHub Web
On any article, click the pencil icon **Edit Suggest** in the reaction bar at the bottom. GitHub will open the Markdown editor in your browser to submit a quick PR.

### Method 2: Via Local Git Branch
```bash
git checkout -b docs/fix-article-slug
# Edit the file under content/posts/article-slug.md
git commit -m "docs: correct memory allocation snippet"
git push origin docs/fix-article-slug
```

---

## Official Contributor Attribution

Whenever your correction PR is merged, your GitHub username and profile avatar are prominently featured in the article's byline as an official **CONTRIBUTOR**.
