# Kebijakan Privasi

**Terakhir diperbarui: Agustus 2026**

Daemontalk beroperasi dengan prinsip utama bebas pelacak (*zero-tracker*). Aktivitas membaca, data pribadi, dan privasi Anda terlindungi secara penuh.

## 1. Bebas Pelacak & Tanpa Iklan Pihak Ketiga

- **Tanpa Skrip Pelacak Perilaku**: Situs ini tidak menggunakan Google Analytics, Facebook Pixel, jaringan iklan bertarget, atau skrip pelacak sidik jari perangkat (*fingerprinting*).
- **Tanpa Jaringan Iklan Komersial**: Kami tidak memasang iklan banner atau menjual data pengunjung kepada pialang data (*data broker*).
- **Infrastruktur Mandiri**: Seluruh aset statis, font, dan skrip dikirimkan langsung dari server mandiri kami untuk meminimalkan paparan pengawasan pihak luar.

## 2. Penyimpanan Lokal & Preferensi Pembaca

Kami menggunakan fitur bawaan browser `localStorage` semata-mata di perangkat Anda untuk menyimpan preferensi membaca non-identifikasi:

- Daftar artikel yang disimpan di Markah Bacaan (*Bookmarks*).
- Pilihan tema tampilan aktif (*Mode Terang, Gelap, atau Sepia*).
- Pilihan tipografi dan intensitas kehangatan layar (*Warm Screen Tint*).

**Penting**: Data preferensi ini berada 100% di memori lokal peramban Anda, tidak pernah diunggah, disinkronkan, atau dikirimkan ke server kami maupun pihak ketiga mana pun.

## 3. Telemetri Server & Log Keamanan Sementara

Saat mengakses Daemontalk, server mencatat metadata koneksi HTTP standar:

- Alamat IP koneksi.
- URL dan Metode Request HTTP.
- Informasi User-Agent dan header Referrer.
- Kode Status Response dan waktu latensi.

**Kebijakan Retensi Log**: Data log dikumpulkan murni untuk audit keamanan *real-time*, pembatasan beban akses (*rate-limiting*) terhadap serangan DDoS/brute-force, serta pemantauan kestabilan server. Log ini akan dirotasi dan dihapus permanen secara otomatis setelah **14 hari**. Data ini tidak pernah dijual, dibagikan, atau digunakan untuk pembuatan profil pengguna.

## 4. Partisipasi Interaktif (Komentar & Buku Tamu)

Saat Anda memilih untuk mengirimkan komentar pada artikel atau pesan pada Buku Tamu publik:

- **Visibilitas Publik**: Nama alias (*Callsign*) dan isi pesan yang Anda ketikkan disimpan di basis data SQLite lokal kami dan ditampilkan secara terbuka di halaman situs.
- **Perlindungan Honeypot**: Formulir menggunakan mekanisme *honeypot* tak kasat mata untuk menyaring bot spam tanpa membebani pembaca dengan CAPTCHA komersial yang mengganggu.
- **Tanpa Kewajiban Registrasi**: Anda tidak diwajibkan mendaftarkan kata sandi, email, atau akun media sosial untuk berdiskusi di lab ini.

## 5. Retensi Data & Hak Penghapusan

Anda berhak meminta ralat atau penghapusan permanen atas komentar maupun pesan buku tamu yang telah Anda kirimkan sebelumnya. Silakan ajukan permohonan melalui email ke **realdaemontalk@gmail.com** dengan menyertakan tautan artikel dan nama alias yang Anda gunakan.

## 6. Tautan Eksternal

Artikel di situs ini dapat memuat tautan ke repositori GitHub eksternal, dokumentasi resmi, dan paper akademik. Saat Anda berpindah dari Daemontalk, aktivitas penjelajahan Anda tunduk pada kebijakan privasi masing-masing situs tujuan tersebut.

Jika Anda memiliki pertanyaan, saran, atau kekhawatiran terkait perlindungan privasi di situs web ini, silakan hubungi kami di: **realdaemontalk@gmail.com**.
